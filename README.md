# DeepSeek-GitHub

王伟轩的个人前端练习仓库。全部作品都是**单个 `.html` 文件**：下载后双击就能打开，不装环境、不装依赖、不用开服务器。

## 作品

| 文件 | 是什么 | 技术点 |
|---|---|---|
| [`demos/固沙.html`](demos/固沙.html) | 横版防守小游戏：沙按行推进，点空地种树挡一次，守住 90 秒 | Canvas 逐帧绘制、HUD 实时数值、手感参数集中在 `CONFIG` 常量 |
| [`demos/sprite-sheet-tool.html`](demos/sprite-sheet-tool.html) | 精灵表切帧工具：拖入图片 → 按行列切帧 → 预览与导出 | File API 读本地文件、Canvas 切图、拖放状态、全程不上传服务器 |
| [`demos/juice-lab.html`](demos/juice-lab.html) | 打击感参数实验台：调滑块对比不同手感的动画节奏 | CSS Grid 布局、参数联动、实时预览 |

## 怎么看

1. 点开上表的链接 → 右上角 `Download raw file`
2. 双击下载下来的 `.html`
3. 或者直接 clone 整个仓库，双击 `demos/` 里的文件

## 备注

- 固沙这个题材来自我的专业（水土保持与荒漠化防治），把治沙概念做成了游戏玩法。
- 代码由我和 AI 协作写出；需求、玩法参数、验收标准由我定——每个作品我都写过"怎么一眼看出它坏了"的检查步骤。
